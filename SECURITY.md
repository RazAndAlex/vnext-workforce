# Security

## Reporting a vulnerability

Report a security problem privately through GitHub security advisories:
open the **Security** tab of this repository, choose **Report a vulnerability**,
and describe what you found and how to reproduce it.

Please do not open a public issue for a security problem, and please do not
post it in a pull request.

You get an acknowledgement, and a fix or an explanation of why the report does
not apply. A report stays private until a fix is available.
